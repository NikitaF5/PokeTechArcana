# PokeTech Arcana Launcher — инструкция

## Что это
Свой лаунчер сервера: сам ставит Minecraft 1.21.1 + NeoForge + Java, качает
все моды/конфиги с твоего GitHub и запускает игру с автоконнектом на сервер.
Когда ты обновляешь сборку — у друзей всё подтягивается само при запуске.

## Разовая настройка (ты, ~15 минут)

### 1. Создай репозиторий
GitHub → New repository → имя `PokeTechArcana` (public). Ничего заливать не надо —
файлы поедут в Releases, там лимит 2 ГБ на файл и без ограничений на количество.

### 2. Сделай токен
GitHub → Settings → Developer settings → Personal access tokens (classic) →
Generate new token → галочка `repo` → скопируй.

### 3. Опубликуй сборку
Собери у себя папку с клиентской сборкой (внутри: `mods/`, `config/`, `kubejs/`,
`resourcepacks/` — можно взять с сервера, убрав серверные моды, если такие есть).
Затем в PowerShell:
```powershell
$env:GITHUB_TOKEN = "ghp_твой_токен"
python build_release.py --pack-dir "C:\путь\к\сборке" --tag pack-v1.0.0 `
    --neoforge 21.1.77 --server "адрес.сервера:25565"
```
(версию NeoForge возьми точную из имени файла neoforge-*.jar на сервере)
Скрипт зальёт 217 модов (~10–30 минут первый раз; дальше — только изменённые).

### 4. Собери exe
В `poketech_launcher.py` вверху проверь `GITHUB_REPO = "NikitaF5/PokeTechArcana"`.
Запусти `build_exe.bat`. Получишь `dist\PokeTechLauncher.exe` — его и раздаёшь
друзьям (файл один, ничего ставить не надо; Windows может ругнуться SmartScreen —
«Подробнее → Выполнить в любом случае»).

## Обновление сборки (потом, 1 команда)
Добавил/убрал моды на сервере → повтори шаг 3 с новым тегом (`pack-v1.0.1`).
Неизменённые jar'ы не перезаливаются. Друзьям ничего делать не надо.

## Как это выглядит у друзей
Запустил exe → ввёл ник → двинул ползунок памяти → ИГРАТЬ.
Первый запуск скачает ваниллу+NeoForge+моды (5–15 минут), дальше — секунды.
Игра стартует сразу с коннектом на сервер.

## Детали
- Папка игры: `%APPDATA%\PokeTechArcana` (отдельно от обычного .minecraft).
- Свои личные моды (шейдеры и т.п.) друзья кладут в `%APPDATA%\PokeTechArcana\localmods`
  — синхронизация их не трогает.
- `options.txt` и `servers.dat` никогда не перетираются.
- Авторизация оффлайн (ник) — работает при `online-mode=false` на сервере.
  Лицензионные игроки заходят со своим ником так же.
