# PokeTech Arcana 1.4.3 — Create: фабрика покеболов

## Новая глава квестовой книги

- Добавлена глава **Create: фабрика покеболов** из 50 заданий и 7 этапов.
- Основная линия ведёт слева направо: кинетика → механизмы → конвейер → детали шара → сборка → особые серии → автоматическая фабрика.
- Шесть самостоятельных веток посвящены передаче вращения, обработке, деталям Poké Ball, особым сериям, лекарствам и складской логистике.
- Рецепты деталей Poké Ball согласованы с установленным модом Create Cobblemon Integrations.
- Все зависимости образуют единое дерево без пересекающих посторонние узлы линий.

## Оформление

- Добавлен отдельный книжный фон, рассчитанный по фактическим границам дерева.
- Семь этапов выделены цветными зонами и краткими заголовками.
- Ключевые задания получили иллюстрированные карточки этапов.
- Добавлены русские названия, описания, цели и награды для всех заданий.

## Доставка

Лаунчер автоматически установит новую главу, фон, карточки этапов и переводы.
